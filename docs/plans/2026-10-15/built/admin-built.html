The new admin

Stills from the real pages (local test copy, real GitHub data). On the Harry branch; not deployed. 18 Oct 2026.

1 · THE ADMIN HOME

Every admin and test page as a card, in your groups. Search, filter by owner, and one simple icon per group. Hover any icon, tag or letter to see what it means.

2 · THE TEAM BOARD

Its own page. Each of you has a card with your pushes and a 7-day activity bar. Green tag = the patch note that push went out in. Pull requests and the live site sit underneath and on top.

3 · TAP A PUSH

It opens with the patch note it went out in. Open in Patch notes jumps to that version on the Patch notes tab.

4 · ADMIN MODE

On: the admin tab sits on every page, and opens first on the admin pages for the page you are on. Switch it off in the menu, or in the game's Settings → Developer.

5 · VIDEOS TAB

Three steps and one line to copy, for handing Claude a recording.
