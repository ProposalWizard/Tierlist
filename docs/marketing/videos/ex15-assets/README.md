# ex15 pictures and moving clips (Hardest records to beat)
Kept here so a new chat can rebuild the video (tools/video-factory/work/ is not in git).
- Pictures: Higgsfield GPT Image 2.6 (medium, 2K), from Wikimedia reference photos of Lewandowski, Pelé and Mané; Messi from behind.
  Scenes saved as 1080x1920 JPG; portraits as PNG with the background cut out.
- clips/: Higgsfield Kling 3.0, 5 s, silent, each started from the picture of the same name (re-compressed).
To rebuild: copy pictures to tools/video-factory/work/ex-people/ (story expects .png names: convert or edit the paths),
clips to tools/video-factory/work/clips/, then `python3 make.py stories/ex15-hardest-records.json`.
