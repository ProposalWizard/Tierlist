# Character voices — ElevenLabs vs open source (research, 20 Nov 2026)

Harry: "for voices we either need to use eleven labs or find open source voice connectors/repos"
(Kokoro, offline, 54 voices / 4 British male, not good enough). Third-party figures unverified.

| Option | Quality | British accents | Game licence | Cost (~200k chars) |
|---|---|---|---|---|
| ElevenLabs | top | Scottish, Irish, Cockney etc. in the library | paid plans: commercial use, you own output, no attribution stated; free tier non-commercial; terms don't explicitly cover shipping audio inside an app | Creator $22/mo (121k credits), Pro $99 (600k) → ~$44 |
| Azure / Google / OpenAI TTS | good | Azure has many en-GB voices | not verified | ~$16 / ~$30 per 1M chars; OpenAI ~$0.015/min |
| Qwen3-TTS (2026) | good, voices described in text, cloning | not stated | Apache-2.0 | GPU only |
| Chatterbox | good, clones from ~10 s | — | MIT, watermarked | free |
| Kokoro (today) | okay | 4 British male | Apache-2.0 | free |
| Piper | robotic | en_GB voices | GPL engine, per-voice weights | free |
| Dia / Zonos / Orpheus | good | — | Apache-2.0 (Orpheus also Llama licence) | GPU |
| F5-TTS, XTTS-v2, Fish | strong | — | rejected: non-commercial / paid | — |

Lip-sync: Montreal Forced Aligner (MIT) for phoneme timings; Rhubarb Lip Sync for mouth shapes (licence to confirm).

Recommendation: ElevenLabs (Creator, ~$22–44) for hero characters this week, designed/library
voices, batch from a script with the key stored as a network secret; later Pro, or a rented GPU
running Qwen3-TTS for crowds/journalists. Caveats: get ElevenLabs' written OK for shipping audio in
an app; no cloning of real people without consent; ear-test regional accents.
