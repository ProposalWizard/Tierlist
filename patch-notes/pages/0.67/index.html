Fix

Settings → More → Data credits. Eight lines say where the real football data comes from.

Real moment highlights (a new switch)seenmeasured
Fix

Settings → Full highlights rebuild → Real moment highlights: Off | On. It shows only while the rebuild is On. With it on, 1 in 4 open-play one-on-ones, tight angles and long-range chances becomes a real moment of the same kind, with the real 4 s build-up. 652 moments are allowed in the game.

  • Tested over 120 matches: 24.5% served, right kind 100%.
  • A moment marked “Don’t use” was served 0 times in 400.
A Real moments page: choose which moments the game may useseen
Fix

For each moment: Use in game, Don’t use or Automatic. There is a filter, a count, and a “Commit marks to the game” button. A README explains how to add, remove and edit moments.
