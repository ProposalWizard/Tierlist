The headline: paid items cannot be faked any more

Fixedlive on the siteMikey runs 2 SQL files

The save safety work: a Gems wallet the phone cannot write to, and a guard on every cloud save

Problem

  • The save lives on the phone. The career is worked out on the phone and the server stored whatever it was sent. Anyone with browser tools (F12) could change ★5,000 to ★50,000,000.
  • Worse: anyone could write their own save straight into the database, using the public key every page carries.
  • This matters before real money is involved. A paid item you can fake is a paid item nobody buys.

Why

The game was built to trust the phone. That was fine for a free game. It is not fine for anything you pay for.

Fix 1: the Gems wallet

  • Gems and paid items live only on the server (4 database tables). The phone can read them. It can never write them.
  • The server sets the prices.
  • A tap is never charged twice.
  • Only the server adds gems. Today that is an admin test button.
  • The payment address refuses everything until Apple, Google or Stripe is connected.
  • Test page: Admin → Gems (test).

Fix 2: the Save guard

  • Every cloud save is checked against the last trusted save. It looks at money, skills, training stars, trophies, awards, Ballon d'Or, wage, fame, reputation, career totals and items you did not pay for.
  • It starts in "watch only" mode for a week. It logs what it would block and blocks nothing. After that it can be switched to correct faked numbers.
  • Admins and testers are exempt.

Mikey runs two SQL files

  • star_wallet.sql creates the 4 wallet tables. Until it runs, the Gems test page has nothing to talk to.
  • Check first: SUPABASE_SERVICE_ROLE_KEY is set in Vercel. The guard needs it.
  • star_save_guard.sql closes the direct-database write hole. Run it after the key check.

What this means for you

Nothing changes when you play. If you edit your own save in a browser, the guard now logs it. Once the week of watching ends, it can fix the number back.

Known gaps: what the guard does not cover yet
  • The casino runs on the phone. A lucky week up to ×2,000 is only logged, not stopped.
  • Coins are in the save. Coins are the shop's current premium money. Do not sell Coins for real money. Sell Gems only, once payments are connected.
  • Other places that still trust the phone: Hall of Fame and legend shares, Draft history and records, objectives, stats and XP.
How we know: measured: 15 of 15 cheat edits caught and 0 false alarms in 7,696 saves from 15 simulated careers. Not seen: a real payment (none is connected), and the guard on live saves (it has only just started watching).

1Fixedlive on the sitecore engine file

The wall chased the loose ball after a deflected free kick

Problem

A free kick hit the wall and ran loose. Two or more wall men ran after it, as if they were attackers.

Why

After a deflection, the wall men moved with the back line's shift. They should stay where they are.

Fix

  • Wall men stay out of the back line's shift.
  • At most the nearest one goes for a stopped ball.
