Problem

The real-football pages used StatsBomb data. Its licence does not allow a paid game.

Why

A paid game needs data with a licence that allows it.

Fix

Four free-licence sources were cut down to pattern files the game reads. Each needs a credit line in the game (done 20 Oct, in Settings, see B3).

Wyscout public set (CC BY 4.0): every event1,941
Afriskaut (Apache 2.0): events136
SkillCorner (MIT): positions, phases of play20
IDSSE / DFL (CC BY 4.0): positions 25 times a second7

2,104 matches in all, every source free for a paid game. Afriskaut was removed on 20 Oct (B3 page).
