How these patch notes work
  1. One page per build. Open the one you want.
  2. Check these is the short list at the top. Look at each one in the game.
  3. Each change is Problem → Why → Fix, picture under it.
  4. Tags show how sure we are: seen on a screen, measured as a number, reasoned from the code only, not seen.
  5. Questions live on one page, Patch Notes Questions. After you read a page, press Read and understood on the admin Patch notes page.
