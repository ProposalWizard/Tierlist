How these patch notes work
  1. One page per build. Open the one you want.
  2. Check these is the short list at the top. Look at each one in the game.
  3. Each change is Problem → Why → Fix, with its picture right under it.
  4. The tag says how sure we are: seen on a screen, measured as a number, reasoned from the code only, not seen.
  5. Questions are not on the pages. They are on one page, Patch Notes Questions. Press Read and understood on the admin Patch notes page when you have read a page, so we know.
