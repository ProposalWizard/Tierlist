The admin is split by game, in four levelsseen
Problem

Website games (tierlists, draft, tic-tac-toe) and Road to Ballon d’Or sat in one long admin list. You said: “we may be a production company that makes a lot of games”.

Why

The admin was built when there was one game. The list held 59 pages. Several games need several areas.

Fix

Four levels, top to bottom:

  1. A game tab at the top of every admin page: Road to Ballon d’Or, Website games, Studio. A new game adds a new tab.
  2. A group (for example Real data, Chances, Match tests). The side menu lists only the current game’s groups.
  3. A page. Each group page has two boxes: Admin tools (things in the game that we tune) and Test pages (new things being tried).
  4. The frame around every page: one back arrow top left, the title, the side menu, the Look switch. The eye button at bottom right explains the page.
On 19 Oct the three tabs held 44, 10 and 5 pages (Studio: team board, patch notes, videos, testers). Today they hold 45, 10 and 7.
