3. Android lag: phones were drawing about twice the dots

What Harry saw or asked

Mikey's Galaxy S20 lags. The game treated its graphics chip as desktop-class.

What changed

Android is now capped at 1.5 pixels per point (iPhone unchanged at 2). When the phone is slow, the game softens the picture first and drops shadows last, and never softens in a flicker. The frame meter now names the graphics chip.

How it was tested

Measured, on a simulated S20: screen size, phone browser name and chip name were faked in a desktop browser. It was not a real phone. Honest limit: our build machine has no graphics card, so 3D runs in software and its frame rates are not a phone's. Only Mikey's real S20 can confirm it feels smoother.

Still weak

Fewer dots should help, but we have no real-phone frame rate before or after. Not measured.
