# Match banner font

`LuckiestGuy.woff2` is **Luckiest Guy** by Astigmatic (Brian J. Bonislawsky),
from the Google Fonts repository (`apache/luckiestguy`). Licence: Apache 2.0,
full text in `LICENSE-LuckiestGuy.txt`. Free to use and ship.

Cut down to plain letters, numbers and punctuation (`pyftsubset`, latin only,
11 KB) for the in-match action banners (`components/star/ArcadeBanner.tsx`,
"Arcade pop", Harry 14 Oct 2026). Everything else in the banner (gradient,
outline, 3D drop, starburst) is drawn in code, so any word gets the same look.
