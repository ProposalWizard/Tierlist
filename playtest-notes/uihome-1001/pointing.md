# Pointing moments: where Harry's mouse was when he said "here", "this", "there" (uihome-1001)

Harry said he was pointing at things with the mouse while talking. This file lines the cursor up with the words, using the original video (re-downloaded, then deleted).

How it was done: word-level timestamps from medium.en (no silence skipping); the cursor was found in every frame at 5 per second (the pure-black arrow, or the hand pointer over buttons), then each pointing word was checked against the frames from 0.5 s before to 1 s after. Cursor positions are measured, not guessed, unless a row says "by eye". Where the cursor is off the phone column, hidden, or only passing through, the row says so and is not rated CLEAR.

Confidence: **CLEAR** = cursor resting on one element, or the words name it and nothing contradicts. **LIKELY** = cursor on or sweeping the area, meaning follows from the cursor plus context. **UNCLEAR** = cursor not on anything useful, so the pointing does not help.
